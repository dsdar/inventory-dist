Home Inventory

Install the Home Inventory platform on a Raspberry Pi 3 or 4.

  1. Flash Raspberry Pi OS Lite (64-bit) with Raspberry Pi Imager. In its settings, set a hostname, user, Wi-Fi and enable SSH.
  2. Power on the Pi and connect with ssh <user>@<hostname>.local.
  3. Run:
curl -fsSL https://dsdar.github.io/inventory-dist/install.sh | sudo bash
